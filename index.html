05 — ВОПРОСЫ

Коротко.

Где узнать все команды? +

В Discord используй /help. На этой странице есть поиск по командам из исходного кода.

Демо управляет сервером? +

Нет. Команды на сайте — локальная демонстрация. Они не выполняют действия в Discord.

Как подключить Esil? +

Перейди по кнопке «Добавить Esil». Если ссылка приглашения ещё не настроена, откроется сервер поддержки.
