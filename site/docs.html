GUIDE / VIVIAN

Начало работы.

1. Добавить бота

Используйте официальную ссылку приглашения. Выберите сервер, которым имеете право управлять, и проверьте запрашиваемые разрешения.

2. Найти команды

В Discord введите /help. Большинство функций доступны через slash-команды. Для карточки участника — /card, для активности — /activity.

3. Музыка

Подключитесь к голосовому каналу и используйте !play запрос или панель /queue, если они доступны в текущем развёртывании. Администратору не требуется самостоятельно устанавливать Lavalink для использования уже настроенного бота.

4. Приватные комнаты

Используйте /room create или /room setup в зависимости от прав и назначения. Не давайте боту больше разрешений, чем необходимо.

5. Социальные функции

Команды /crush, /story_post, /capsule create, /vibecheck доступны согласно настройкам и текущему состоянию бота. Смотрите доступные подкоманды через подсказки Discord.

6. Поддержка и данные

По вопросам доступа и удаления данных используйте сервер поддержки и прочитайте политику конфиденциальности.
